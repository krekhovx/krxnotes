--- Общая информация о языках

Статические языки
* Пример: C.
* Типы проверяются при компиляции.
* Ошибки с типами ловятся заранее.
* Программа компилируется в бинарник.

Динамические языки
* Примеры: Python, Ruby, Bash.
* Требуется интерпретатор.
* Типы определяются во время выполнения.
* Ошибки с типами могут проявиться только в рантайме.

Статические (компилируемые):
* C
  - Нет сборщика мусора.
  - Память вручную: malloc/free.
  - Типы проверяются при компиляции.
  - Нет интерпретатора: создаётся самостоятельный бинарник.

Динамические (интерпретируемые):
* Python
* Ruby
* Bash / Shell
  - Типы определяются в рантайме.
  - Есть автоматическое управление памятью (Python, Ruby).
  - Требуют установленного интерпретатора. Зависят от его версии.

POSIX
* Не тип языка, а стандарт.
* C лежит в основе POSIX API.
* Bash частично следует POSIX.
* Python и Ruby не имеют отношения к POSIX.

Где лучше применять:

* C
  - Максимальная скорость, минимальные зависимости.
  - Лучший выбор для TUI, утилит, системных инструментов, когда важны
    отзывчивость и отсутствие интерпретатора.

* Python
  - Быстрая разработка, много библиотек.
  - Минус: нужен интерпретатор, зависимость от версии.
  - Хорош для скриптов, CLI-утилит, автоматизации, небольших TUI без критичных
    требований к скорости.

* Ruby
  - Похож на Python, но меньше экосистема.
  - Подходит для скриптов и простых TUI, если уже знаком.

* Bash
  - Только для мелких скриптов.
  - Не подходит для интерактивного TUI и высокой скорости.

В языках Python, Ruby и других, есть автоматическая функциональность
освобождения памяти. А Си доверяет программисту и ставит гарантии на то, что
программист освободит память с помощью free(). Такая функциональность называется
"автоматическое управление памятью - сборщик мусора".
